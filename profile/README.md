**Blazor UI components you own.** Headless primitives on NuGet, styled components copied into your project as source by the `blaizio` dotnet tool. Tailwind CSS v4, 8 skins, 16 palettes, RTL and WCAG AA out of the box. MIT.

- Documentation and registry: [blaiz.io](https://blaiz.io)
- Source and issues: [blaizio/blaizio](https://github.com/blaizio/blaizio)
- Discussions: [github.com/blaizio/blaizio/discussions](https://github.com/blaizio/blaizio/discussions)
- X: [@blaizio_ui](https://x.com/blaizio_ui)
- Sponsor: [GitHub Sponsors](https://github.com/sponsors/blaizio)

```bash
dotnet tool install -g Blaizio.Cli
blaizio add button card dialog
```
